# Keyboard Shortcuts

- **⌘N** — new note
- **⇧⌘N** — new folder
- **⌘O** — open a different vault
- **⌘S** — save now (notes save themselves anyway)
- **⌘R** — toggle read mode
- **⌘B** / **⌘I** — bold / italic
- **⌘E** — inline code
- **⌥⌘1…3** — heading levels
- **⌘[** / **⌘]** — previous / next note
- **⌘F** — find inside the current note
- **⌘G** / **⇧⌘G** — next / previous match
