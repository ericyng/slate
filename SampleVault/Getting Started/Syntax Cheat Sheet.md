# Syntax Cheat Sheet

## Text

**Bold**, *italic*, ***both***, ~~strikethrough~~, and `inline code`.

A [link](https://example.com) keeps its target hidden in read mode.

## Structure

# Heading 1
## Heading 2
### Heading 3

---

## Lists

- A bullet
  - A nested bullet
- Another bullet

1. First
2. Second
3. Third

- [x] A finished task
- [ ] An open task

## Quotes

> A quote is indented and quiet.
> It can span several lines.

## Code

```swift
struct Note {
    let title: String
    let body: String
}
```
